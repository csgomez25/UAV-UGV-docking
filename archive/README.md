# Archive

Historical material from the project's original phase: summer 2026, a two-person
GPS-denied-drone effort, before the senior-design pivot to Cooperative UAV–UGV Docking
on 2026-09-10. Kept for reference — day-by-day commands, dead-end estimator attempts,
and the reasoning behind decisions that later docs assume without re-explaining — but
none of it is required reading to get started on the current project. Start at the
top-level [README.md](../README.md) instead.

| File | What it is |
|---|---|
| [SIM_WEEK1.md](./SIM_WEEK1.md) | Day-by-day sim bring-up log (ROS 2 Jazzy + PX4 SITL + cuVSLAM/nvblox), written as a solo learning journal |
| [SUMMER.md](./SUMMER.md) | The original 2-person summer pre-work plan (before the team grew) |
| [GPS_DENIED_LOG.md](./GPS_DENIED_LOG.md) | The full GPS-denied-phase status history: the three-gate breakdown, every VIO/estimator candidate tried, the measurement-bug saga, and the pre-2026-09-10 progress log — condensed to a summary in the top-level README |

The GPS-denied work itself is not archived — it continues as the project's research/
mission layer. See the top-level [README.md](../README.md), [ROADMAP.md](../ROADMAP.md),
and [BUILD.md](../BUILD.md).
